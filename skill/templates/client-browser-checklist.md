# ブラウザでの確認のお願い

このシートは、**セキュリティ評価のうち、評価者側では実施できない確認**をお願いするためのものです。

ログインが必要な画面の確認は、評価者がアカウントをお預かりして代行することを避けています。
お手元で操作していただき、**見えたものをそのまま記入**してください。

- 所要時間の目安: 20〜30 分
- 必要なもの: 普段お使いのブラウザ（Chrome / Edge / Safari のいずれか）
- **判断は不要です。** 「良いか悪いか」ではなく、**見えたとおり**をご記入ください

---

## はじめに（共通の準備）

**開発者ツール**を使います。次のキーで開きます。

| | 開き方 |
|---|---|
| Windows | `F12` または `Ctrl` + `Shift` + `I` |
| Mac | `Command` + `Option` + `I` |

Safari の場合は、先に「Safari →設定→詳細→**Web デベロッパー用の機能を表示**」を有効にしてください。

**⚠️ 作業中のお願い**

- **フォームの送信ボタンは押さないでください。** 問い合わせや申し込みが実際に飛んでしまいます
- 購入・予約・退会・削除の操作もお控えください
- 迷ったら**押さずに、その旨をご記入**ください

---

## 1. ログイン情報がどこに保存されているか

**やること**

1. いつもどおりログインする
2. 開発者ツールを開く
3. **Application**（Safari は**ストレージ**）タブを開く
4. 左側の **Local Storage** → サイトの URL を選ぶ
5. **左側に並んでいる「キー」の名前だけ**を書き写す

**記入欄**

```
Local Storage に並んでいた名前:
（例: authToken, theme, user_id ...）


Cookie の一覧（Application → Cookies）で、名前に token / session / auth が
含まれるものはありましたか:
□ あった（名前: 　　　　　　　　　）　　□ 無かった
```

**⚠️ 値（右側の長い文字列）は書き写さないでください。** 名前だけで判断できます。

---

## 2. ログアウトした後に、戻るボタンで見えてしまわないか

**やること**

1. ログインして、**お名前や連絡先が表示されている画面**を開く
2. **ログアウト**する
3. ブラウザの**戻るボタン**を押す

**記入欄**

```
戻るボタンを押した後、さっきの画面はどう見えましたか:
□ 個人情報がそのまま表示された
□ 一瞬表示されてから、ログイン画面に切り替わった
□ すぐログイン画面になった（何も見えなかった）
□ その他（　　　　　　　　　　　　　　　　）
```

共用のパソコンで使われる可能性がある場合、ここは重要な確認になります。

---

## 3. ログアウトしても、まだデータが取れてしまわないか

**やること**

1. ログインした状態で、**データが表示されている画面**（一覧や詳細）を開く
2. その画面の **URL をコピー**しておく
3. **ログアウト**する
4. コピーした URL を**アドレスバーに貼り付けて開く**

**記入欄**

```
ログアウト後にその URL を開いたら:
□ データが表示された
□ ログイン画面に飛ばされた
□ エラーが表示された（内容: 　　　　　　　　　）
```

---

## 4. 権限の無い画面に入れてしまわないか

**管理者用の画面がある場合のみ**お願いします。管理者アカウントをお持ちでない方の視点で確認します。

**やること**

1. **一般の利用者アカウント**でログインする（管理者ではないアカウント）
2. 管理画面の URL を、アドレスバーに直接入力して開く
3. 開発者ツールの **Network**（ネットワーク）タブを開いた状態で行う

**記入欄**

```
画面の見え方:
□ 管理画面が普通に表示された
□ 一瞬中身が見えてから、別の画面に切り替わった
□ 最初から入れなかった

Network タブで、赤くない（成功した）通信の中に、
管理用のデータらしきものは含まれていましたか:
□ 含まれていた　　□ 含まれていなかった　　□ 判断できなかった
```

2 番目と 3 番目は、画面上は同じに見えても中身が違います。**Network タブを見ていただくのはこのためです。**

---

## 5. 他の方のデータが見えてしまわないか

**アカウントを 2 つご用意いただける場合のみ**お願いします。難しければ「未実施」で構いません。

**やること**

1. アカウント A でログインし、データの詳細画面を開く。**URL に含まれる番号や ID を控える**
2. ログアウトし、**アカウント B** でログインする
3. 控えた URL を開く

**記入欄**

```
□ アカウント A のデータが見えた
□ 見えなかった（エラー / 一覧に戻された）
□ 未実施（アカウントを 2 つ用意できなかった）
```

---

## 6. 入力した文字がそのまま画面に出ないか

**やること**

検索欄や、入力内容が画面に表示される欄に、次の文字列を入力します。**送信ボタンは押しません。**
検索欄など、押さないと結果が出ない場合は、検索のみ実行してください。

```
SECTEST-1234
```

**記入欄**

```
入力した文字は、画面にどう出ましたか:
□ そのまま「SECTEST-1234」と表示された
□ 表示されなかった
□ その他（　　　　　　　　　　　　　　　　）

そのページの URL:
```

**これは動作を壊す操作ではありません。** ただの文字列で、何も起きないのが正常です。

## ご返送について

- **記入したこのシート**をお送りください
- 画面の写真を撮っていただける場合は、**個人情報の部分を隠して**からお願いします
- 「よく分からなかった」「途中で止めた」もそのままお書きください。**未確認であることが分かるほうが、確認したつもりで進むより安全です**

ご不明な点があれば、途中で止めてご連絡ください。
