# 管理画面の設定の確認のお願い

このシートは、**各サービスの管理画面にある設定**を確認するためのものです。
評価者が管理画面のアカウントをお預かりすることは避けています。お手元で画面を開き、
**表示されている項目名と値を、そのまま書き写して**ください。

- 所要時間の目安: 30〜45 分（使っているサービスの数による）
- **判断は不要です。** 「良いか悪いか」ではなく、**画面に出ている項目名と値**をご記入ください
- 画面の名前や場所は、サービス側の変更で変わることがあります。見つからなければ「見つからなかった」とお書きください

---

## 記入欄（最初に）

```
サービス名:
対象の URL:
実施日時:
使ったアカウントの種類（例: 組織の管理者 / 開発者 / 閲覧のみ）:
```

---

## ⚠️ 作業中のお願い

- **設定を変えないでください。** スイッチやボタンには触れず、見るだけにしてください。開いた画面は閉じるだけで構いません
- **鍵・トークン・パスワード・接続文字列の値は、書き写さないでください。** 書いていただくのは、**名前・種類・有効か無効か・作成日・最後に使われた日**までです
- メンバーの一覧は、**人数と役割の内訳**だけで構いません。お名前やメールアドレスは不要です
- 画面の写真を撮っていただける場合は、鍵の値や個人の情報の部分を隠してからお願いします
