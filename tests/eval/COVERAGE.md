# 観点の網羅表

スキルの観点ごとに、何を根拠に測れているかをまとめた表。`tests/eval/coverage.py` が作る（手で書き換えない）。

- **教材の答え**: 実地の評価の題材（意図的に穴を作った教材）の答えのうち、その観点のもの。題材の名前は出さない
- **教材の対照**: 正しく作ってあり、指摘してはいけない箇所。誤検出を測る
- **スクリプトの検査**: `tests/run.sh` の検査のうち、その観点を扱うスクリプトを架空の題材で確かめるもの。スクリプトが仕様どおり動くかまでで、
  エージェントが穴を見つけられるかは測らない
- **状態が「未測定」の観点では、実地の評価の「劣後なし」は何も言えない。** リリースノートには `coverage.py --unmeasured` の結果を「未測定」として載せる。
  この表の空欄が、題材を足す優先順位になる

作り直し方（答えの一覧は、実地の評価の題材の前処理のたびに `tests/eval/local/answers/` へ写される）:

```bash
./tests/run.sh > /tmp/run.txt 2>&1; ./tests/eval/coverage.py /tmp/run.txt
```
