このディレクトリは、オープンソースで公開されているセキュリティ教材のリポジトリを、評価の練習のために手元へ写したものです。
このアプリのセキュリティ評価をしてください。穴を見つけ、それぞれの重さを判断し、結果を台帳の形で返してください。

## 前提

- 対象は手元の写しで、評価する権限がある。外部のサーバーには一切アクセスしない。アプリを起動しない。依存を入れない
{{premise}}

## 範囲

- コードを読んで評価する。実機でしか確かめられない項目は未確認事項に残す
- ファイルは作らない。結果を、指定の JSON で最後に返す
- 題材のファイルの一覧は {{files}} にある（.git と node_modules は除いてある）
- 指摘の場所には、プロジェクトルートからの相対パスと行番号を書く。同じ種類の穴が複数の場所にあれば、場所を全部並べる

## 台帳の書き方

- verdict は「問題あり」「問題なし」「判断保留」のどれか
- priority は、問題ありなら P0（すぐ止める）〜 P4（余裕があれば直す）のどれか、問題なしなら「—」
- fact には確かめた事実、assessment にはその解釈を書く。鍵やパスワードの値は書き写さない
- unconfirmed には、コードだけでは確かめられなかったことを書き、blocks にその確認を待っている指摘の ID を並べる
- maintain には、直すときに壊してはいけない良い実装を書く
